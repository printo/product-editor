Click any date cell on the calendar to add events or replace it with an image.

Mockup notes

  • Date number is always visible (top-right of each cell) unless the cell has an imageOverride.
  • Holiday pills auto-load from storage/holidays/en-IN/<year>.json (seeded from Nager.Date). User can't delete them — only override the whole cell with an image.
  • User event pills stack below holidays. Cap = 3 per cell; +N more when overflow.
  • Cell text auto-fits to the cell width (the real renderer uses a binary-search font-size helper; this mockup uses CSS text-overflow: ellipsis for simplicity).
  • Themes map to storage/calendar_styles/{modern-minimalist,modern-genz,weekday-highlight}.json. Ops picks at layout creation; customer can't switch.
  • Image override replaces the entire cell content. The real implementation reuses the existing chunked-upload + MediaPipe auto-orientation pipeline.
  • The 300 DPI server-rendered output will look identical to this preview (paritied via PRD §4.3 "identical math").
